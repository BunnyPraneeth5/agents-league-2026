## Purpose

This internal guide helps engineering managers, learning leads, and certification coaches align learners to Microsoft Azure certification paths. It summarizes expected role fit, core skills, study time, difficulty, and prerequisites for four common engineering certifications used in the enablement program.

## Certification Paths

### AZ-204: Developing Solutions for Microsoft Azure

- Target role: Cloud Application Developer
- Key skills covered: Azure compute solutions, Azure storage integration, authentication and authorization, Azure Functions, monitoring and optimization
- Recommended study hours: 45
- Difficulty level: Intermediate
- Prerequisites: Basic Azure services knowledge, professional experience with Python, C#, JavaScript, or Java, and familiarity with REST APIs

Recommended for engineers who build, deploy, and troubleshoot cloud-native applications. Learners should already be comfortable reading application logs, using SDKs, and reasoning about API behavior.

### AZ-400: Designing and Implementing Microsoft DevOps Solutions

- Target role: DevOps Engineer or Platform Engineer
- Key skills covered: Source control strategy, continuous integration, continuous delivery, infrastructure as code, security and compliance in pipelines
- Recommended study hours: 50
- Difficulty level: Advanced
- Prerequisites: Experience with Azure administration or development, working knowledge of Git, and familiarity with build and release pipelines

Recommended for engineers who own delivery workflows, deployment reliability, release governance, and pipeline automation. Learners should have hands-on exposure to CI/CD before starting this path.

### AZ-305: Designing Microsoft Azure Infrastructure Solutions

- Target role: Cloud Solutions Architect
- Key skills covered: Identity and governance design, business continuity planning, compute architecture, data storage architecture, network architecture
- Recommended study hours: 60
- Difficulty level: Advanced
- Prerequisites: Azure administration experience, understanding of networking, security, and virtualization, and ability to translate business requirements into technical designs

Recommended for senior engineers and architects responsible for designing scalable Azure solutions. Learners should be prepared for scenario-based questions that require tradeoff analysis.

### DP-203: Data Engineering on Microsoft Azure

- Target role: Data Engineer
- Key skills covered: Data ingestion, data transformation, data storage design, pipeline orchestration, data security and monitoring
- Recommended study hours: 55
- Difficulty level: Intermediate
- Prerequisites: SQL fundamentals, experience with data processing concepts, and basic Azure storage and compute knowledge

Recommended for engineers working with analytics platforms, data movement, transformation jobs, and production data pipelines. Learners should be comfortable with batch and streaming data concepts.

## Recommended Study Pattern

The enablement team recommends a four-phase study pattern:

1. Orientation and objectives review: Spend the first 10 percent of study time reviewing exam domains, skill gaps, and role relevance.
2. Guided learning: Use structured modules and internal notes for 40 percent of study time, with short checks after each topic.
3. Hands-on labs: Reserve 30 percent of study time for implementation practice, troubleshooting, and environment setup.
4. Practice assessment and review: Use the final 20 percent for practice questions, weak-area review, and exam readiness planning.

Learners with fewer than 12 focus hours per week should use smaller study blocks of 45 to 60 minutes. Learners with 18 or more focus hours per week can use deeper lab blocks of 90 to 120 minutes, especially for architecture, data engineering, and DevOps scenarios.

## Manager Guidance

Managers should confirm that the selected certification maps to the learner's current or next role. Study plans should be protected on calendars, reviewed weekly, and adjusted when practice scores remain below 70 percent. For advanced certifications, pair learners with a mentor who has recent hands-on experience in the target domain.
